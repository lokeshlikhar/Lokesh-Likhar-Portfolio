# 💼 Personal Portfolio Website

A modern and responsive personal portfolio website built using **React.js, JavaScript, HTML5, and CSS3**. The website showcases my skills, projects, and background as a Full Stack Developer with a focus on AI-powered applications.

## 🔗 Live Preview

**🌐 Live Website:**https://lokesh-likhar-portfolio.onrender.com/

---

## ✨ Key Features

* 👨‍💻 Personal introduction and professional profile
* 🛠️ Showcase of technical skills
* 🚀 Project showcase with GitHub and live demo links
* 🤖 Highlight of AI-powered projects
* 📱 Fully responsive user interface
* 🌙 Dark and light mode
* 📄 Resume section
* 📬 Contact form
* 🔗 GitHub and LinkedIn links

---

## 🛠 Tech Stack

* **Frontend:** React.js, JavaScript
* **Styling:** HTML5, CSS3
* **Icons:** React Icons
* **Deployment:** Render
